# Security policy

The project is pre-alpha and does not yet accept public security reports through
an established public intake. Invited pilot testers should use the private
contact channel through which they received access. Do not include credentials,
invitation secrets, personal data, room traffic, stream URLs, or viewing
information in a public issue.

Before testing expands beyond the invitation-only pilot, this document will
identify a dedicated private reporting channel, supported versions, expected
response process, and coordinated disclosure policy.
